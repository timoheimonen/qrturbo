    Comment fonctionne un QR code vCard

    Un QR code vCard contient une carte de visite numérique au format vCard. Lorsqu’on le scanne, le téléphone propose d’enregistrer les informations comme nouveau contact : rien à saisir à la main.

    Ne remplissez que les champs que vous souhaitez partager. Plus vous ajoutez d’informations, plus le code devient dense : imprimez-le donc sur au moins 2,5 cm de large et testez-le avant de commander un grand lot de cartes.

    Comme les informations sont encodées directement dans le code, elles ne peuvent pas être modifiées par la suite. Si votre numéro ou votre fonction change, créez un nouveau code pour votre prochaine impression.

    Questions fréquentes

    Les QR codes créés avec QRTurbo.app expirent-ils ?

    Non. QRTurbo.app crée des QR codes statiques : votre lien, votre texte ou vos coordonnées sont encodés directement dans le code. Il n’y a aucun serveur intermédiaire, donc rien ne peut expirer ni être désactivé. Un code fonctionne tant que son contenu reste valide, par exemple tant que le site vers lequel il pointe existe.

    Pourquoi mon QR code créé sur un autre site ne fonctionne-t-il plus ?

    De nombreux générateurs créent par défaut des QR codes dynamiques. Ceux-ci contiennent un lien court vers le serveur du fournisseur, qui redirige chaque scan vers votre véritable adresse. À la fin de l’essai gratuit ou de l’abonnement, le fournisseur coupe la redirection et le code imprimé cesse de fonctionner. Les codes de QRTurbo.app contiennent votre vrai contenu et ne dépendent jamais de nous.

    QRTurbo.app est-il vraiment gratuit ? Puis-je utiliser les codes à des fins commerciales ?

    Oui. Pas d’inscription, pas d’essai, pas de filigrane et pas de limite de scans. Vous pouvez utiliser les QR codes que vous créez à des fins personnelles comme commerciales, par exemple sur des cartes de visite, des menus, des emballages ou de la publicité.

    Puis-je modifier un QR code après l’avoir imprimé ?

    Non. Un QR code statique ne peut pas être modifié, car le contenu fait partie du motif. Si vous pensez changer la destination, créez le code vers une adresse que vous contrôlez, comme une page de votre propre site, et mettez plutôt cette page à jour.

    À quelle taille faut-il imprimer un QR code ?

    Imprimez-le sur au moins 2 × 2 cm. En règle générale, le code doit mesurer au moins un dixième de la distance de lecture : une affiche lue à 2 mètres nécessite un code d’environ 20 cm. Pour l’impression, téléchargez un PDF ou un SVG, qui restent nets à toutes les tailles, et indiquez la largeur d’impression exacte. QRTurbo.app affiche la taille des modules et vous avertit lorsque le code est trop petit pour être scanné. Laissez vide la zone calme (marge) autour du code.

    Pourquoi mon QR code ne se scanne-t-il pas ?

    Les causes les plus fréquentes sont un contraste trop faible entre le code et son fond, une zone calme trop petite, un logo qui masque une trop grande partie du code, ou trop de contenu pour la taille d’impression. QRTurbo.app vérifie chaque code avec un scanner intégré, directement sur votre appareil, et vous suggère des corrections. Testez toujours le code avec plusieurs téléphones avant de l’imprimer.

    Mes données sont-elles en sécurité ? Pouvez-vous voir mon mot de passe WiFi ?

    Vos données restent sur votre appareil. Le QR code est généré par du code exécuté dans votre navigateur, et rien de ce que vous saisissez ou importez n’est envoyé à un serveur : personne ne peut voir votre mot de passe WiFi ni vos coordonnées. Après la première visite, le générateur fonctionne aussi hors ligne.

    Quel format de fichier choisir ?

    Utilisez le PNG pour les écrans, les documents et la plupart des imprimantes. Utilisez le SVG pour les sites web et les logiciels de graphisme, et le PDF pour les imprimeurs : ces deux formats vectoriels restent nets à toutes les tailles. L’EPS est destiné aux anciens logiciels de graphisme et de signalétique. Le JPG et le WebP sont des images légères pour les applis et les sites web. Tous les formats sont gratuits et conservent vos couleurs, votre logo et votre cadre.
