    QR codes grátis que nunca param de funcionar

    Muitos geradores de QR code “grátis” criam códigos dinâmicos que apontam para o próprio servidor de redirecionamento. Quando o período de teste acaba, o código é desativado, muitas vezes quando já foi impresso em cardápios, cartões de visita ou embalagens. O QRTurbo.app funciona de outro jeito.

    Onde fica o seu conteúdo? No servidor do provedor, atrás de um link curto de redirecionamento Dentro do próprio QR code
    O que acontece quando o teste acaba? O código é desativado até você pagar Nada. Não existe período de teste, e o código continua funcionando
    Precisa criar uma conta? Geralmente, sim Não
    Quem vê as suas leituras? Cada leitura passa pelo provedor Ninguém. As leituras nunca chegam até nós
    Quanto custa? Uma assinatura mensal ou anual Nada, inclusive para uso comercial

    A única desvantagem: um QR code estático não pode ser editado depois de impresso. Se você talvez precise mudar o destino mais tarde, crie o código para uma página que você controla e atualize essa página.

    Privado desde a concepção

    QR codes costumam carregar dados pessoais: uma senha do WiFi, um número de telefone, um endereço residencial. O QRTurbo.app foi feito para que nada disso chegue a um servidor.

    Fica no seu dispositivo

    Os QR codes e os logos são gerados por código que roda no seu navegador. Não existe nenhum servidor que possa receber o que você digita.

    Sem redirecionamento, sem prazo de validade

    Seu conteúdo é codificado diretamente no QR code. As leituras nunca passam por nós, e o código nunca expira.

    Sem rastreamento

    Sem análises, anúncios, cookies ou contas. Só as suas preferências de idioma, tema e download são salvas, localmente no seu navegador.

    Aberto para inspeção

    Perguntas frequentes

    Os QR codes criados com o QRTurbo.app expiram?

    Não. O QRTurbo.app cria QR codes estáticos: o seu link, texto ou dados de contato são codificados diretamente no código. Não há nenhum servidor no meio, então não há nada que possa expirar ou ser desativado. O código continua funcionando enquanto o conteúdo for válido, por exemplo, enquanto existir o site para o qual ele aponta.

    Por que o meu QR code de outro site parou de funcionar?

    Muitos geradores criam QR codes dinâmicos por padrão. Eles contêm um link curto para o servidor do provedor, que redireciona cada leitura para o seu endereço real. Quando o teste grátis ou a assinatura termina, o provedor desliga o redirecionamento e o código impresso para de funcionar. Os códigos do QRTurbo.app contêm o seu conteúdo real e nunca dependem de nós.

    O QRTurbo.app é grátis mesmo? Posso usar os códigos para fins comerciais?

    Sim. Não há cadastro, período de teste, marca d’água nem limite de leituras. Você pode usar os QR codes que criar para fins pessoais e comerciais, como cartões de visita, cardápios, embalagens e publicidade.

    Posso alterar um QR code depois de imprimir?

    Não. Um QR code estático não pode ser editado, porque o conteúdo faz parte do próprio desenho do código. Se você acha que vai mudar o destino, crie o código para um endereço que você controla, como uma página do seu próprio site, e atualize essa página.

    De que tamanho devo imprimir um QR code?

    Imprima com pelo menos 2 × 2 cm. Como regra prática, o código deve ter pelo menos um décimo da distância de leitura: um cartaz lido a 2 metros precisa de um código de uns 20 cm. Para impressão, baixe um PDF ou SVG, que ficam nítidos em qualquer tamanho, e defina a largura exata de impressão. O QRTurbo.app mostra o tamanho dos módulos e avisa quando o código está pequeno demais para ser lido. Deixe vazia a zona de silêncio ao redor do código.

    Por que o meu QR code não está sendo lido?

    As causas mais comuns são pouco contraste entre o código e o fundo, uma zona de silêncio pequena demais, um logo que cobre boa parte do código ou conteúdo demais para o tamanho impresso. O QRTurbo.app verifica cada código com um leitor integrado no seu dispositivo e sugere correções. Teste sempre o código com alguns celulares diferentes antes de imprimir.

    Meus dados estão seguros? Vocês conseguem ver a minha senha do WiFi?

    Seus dados ficam no seu dispositivo. O QR code é gerado por código que roda no seu navegador, e nada do que você digita ou envia vai para um servidor, então ninguém consegue ver a sua senha do WiFi nem os seus dados de contato. Depois da primeira visita, o gerador também funciona offline.

    Qual formato de arquivo devo usar?

    Use PNG para telas, documentos e a maioria das impressoras. Use SVG para sites e ferramentas de design, e PDF para gráficas: os dois são arquivos vetoriais que ficam nítidos em qualquer tamanho. O EPS serve para programas mais antigos de design e de plotagem. JPG e WebP são arquivos de imagem leves para apps e sites. Todos os formatos são grátis e mantêm as suas cores, o logo e a moldura.
