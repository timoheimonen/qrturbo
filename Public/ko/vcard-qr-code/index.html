    vCard QR코드의 원리

    vCard QR코드에는 vCard 형식의 디지털 명함이 담겨 있습니다. 상대방이 스캔하면 휴대폰이 새 연락처로 저장할지 물어보므로 손으로 입력할 필요가 없습니다.

    공유하고 싶은 항목만 입력하세요. 정보가 많을수록 코드가 촘촘해지므로 가로 최소 2.5cm 크기로 인쇄하고, 명함을 대량 주문하기 전에 꼭 스캔 테스트를 해 보세요.

    정보가 코드에 직접 인코딩되므로 나중에 수정할 수 없습니다. 전화번호나 직함이 바뀌면 다음 인쇄 때 새 코드를 만드세요.

    평생 멈추지 않는 무료 QR코드

    “무료”를 내세우는 많은 QR코드 생성기는 자사 리디렉션 서버를 거치는 동적 QR코드를 만듭니다. 체험 기간이 끝나면 코드가 비활성화되는데, 이미 메뉴판이나 명함, 포장재에 인쇄된 뒤인 경우가 많습니다. QRTurbo.app은 다르게 작동합니다.

    설계부터 비공개

    QR 코드에는 WiFi 비밀번호, 전화번호, 집 주소 같은 개인 정보가 담기는 경우가 많습니다. QRTurbo.app은 이런 정보가 절대 서버에 닿지 않도록 만들어졌습니다.

    기기에만 남습니다

    QR 코드와 로고는 브라우저에서 실행되는 코드로 생성됩니다. 입력한 내용을 받을 서버가 없습니다.

    추적 없음

    분석, 광고, 쿠키, 계정이 없습니다. 언어, 테마, 다운로드 설정만 브라우저에 로컬로 저장됩니다.

    자주 묻는 질문

    QRTurbo.app으로 만든 QR코드에 유효기간이 있나요?

    없습니다. QRTurbo.app은 정적 QR코드를 만듭니다. 링크, 텍스트, 연락처 정보가 코드에 직접 인코딩되며 중간에 서버가 없기 때문에 만료되거나 차단될 일이 없습니다. 내용이 유효한 동안, 예를 들어 연결된 웹사이트가 남아 있는 동안에는 코드가 계속 작동합니다.

    다른 사이트에서 만든 QR코드가 왜 갑자기 작동하지 않나요?

    많은 생성기는 기본적으로 동적 QR코드를 만듭니다. 이런 코드에는 업체 서버로 가는 짧은 링크가 담겨 있고, 스캔할 때마다 서버가 실제 주소로 리디렉션합니다. 무료 체험이나 구독이 끝나면 업체가 리디렉션을 끊어 버리고, 인쇄된 코드는 더 이상 작동하지 않습니다. QRTurbo.app에서 만든 코드에는 실제 내용이 담겨 있어 저희에게 전혀 의존하지 않습니다.

    QRTurbo.app은 정말 무료인가요? 상업적으로 사용해도 되나요?

    네. 가입, 체험 기간, 워터마크, 스캔 횟수 제한이 모두 없습니다. 만든 QR코드는 명함, 메뉴판, 포장재, 광고 등 개인적·상업적 용도로 자유롭게 사용할 수 있습니다.

    인쇄한 QR코드를 나중에 수정할 수 있나요?

    아니요. 정적 QR코드는 내용이 패턴 자체의 일부이기 때문에 수정할 수 없습니다. 연결 대상이 바뀔 가능성이 있다면 내 웹사이트의 페이지처럼 직접 관리하는 주소로 코드를 만들고, 그 페이지를 수정하세요.

    QR코드는 어느 정도 크기로 인쇄해야 하나요?

    최소 2 × 2cm 크기로 인쇄하세요. 스캔 거리의 10분의 1 이상을 기준으로 삼으면 됩니다. 예를 들어 2m 떨어진 곳에서 보는 포스터라면 약 20cm 크기의 코드가 필요합니다. 인쇄용으로는 어떤 크기에서도 선명한 PDF나 SVG를 다운로드하고 정확한 인쇄 너비를 설정하세요. QRTurbo.app은 모듈 크기를 보여 주고, 코드가 너무 작아 스캔하기 어려우면 경고합니다. 코드 주변의 여백(정적 영역)은 비워 두세요.

    QR코드가 스캔되지 않는 이유는 무엇인가요?

    가장 흔한 원인은 코드와 배경의 대비가 낮거나, 여백이 너무 좁거나, 로고가 코드를 너무 많이 가리거나, 인쇄 크기에 비해 내용이 너무 많은 경우입니다. QRTurbo.app은 내장 스캐너로 모든 코드를 기기에서 바로 검사하고 해결 방법을 제안합니다. 인쇄하기 전에 항상 여러 휴대폰으로 테스트해 보세요.

    내 데이터는 안전한가요? 와이파이 비밀번호를 볼 수 있나요?

    데이터는 내 기기에만 남습니다. QR코드는 브라우저에서 실행되는 코드로 생성되며, 입력하거나 업로드한 내용은 어떤 서버로도 전송되지 않습니다. 그래서 누구도 와이파이 비밀번호나 연락처 정보를 볼 수 없습니다. 처음 한 번 방문한 뒤에는 오프라인에서도 생성기를 사용할 수 있습니다.

    어떤 파일 형식을 사용해야 하나요?

    화면, 문서, 대부분의 프린터에는 PNG를 사용하세요. 웹사이트와 디자인 도구에는 SVG를, 인쇄소에는 PDF를 사용하세요. 둘 다 어떤 크기에서도 선명한 벡터 파일입니다. EPS는 구형 디자인 및 간판 제작 소프트웨어용입니다. JPG와 WebP는 앱과 웹사이트에 알맞은 작은 이미지 파일입니다. 모든 형식은 무료이며 색상, 로고, 프레임이 그대로 유지됩니다.
