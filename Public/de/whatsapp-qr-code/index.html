    So funktionieren WhatsApp QR-Codes

    Ein WhatsApp QR-Code enthält einen wa.me-Link. Beim Scannen öffnet sich ein Chat mit Ihnen, und Ihre vorausgefüllte Nachricht ist sofort bereit zum Senden.

    Geben Sie die Nummer im internationalen Format mit Ländervorwahl ein, zum Beispiel +49 151 23456789. Leerzeichen und Bindestriche werden automatisch entfernt.

    Der Code enthält den wa.me-Link selbst, keine Weiterleitung. Er funktioniert also, solange die Nummer WhatsApp nutzt.

    Häufig gestellte Fragen

    Laufen QR-Codes von QRTurbo.app ab?

    Nein. QRTurbo.app erstellt statische QR-Codes: Ihr Link, Text oder Ihre Kontaktdaten sind direkt im Code gespeichert. Dazwischen gibt es keinen Server, also nichts, was ablaufen oder abgeschaltet werden könnte. Ein Code funktioniert, solange sein Inhalt gültig ist, zum Beispiel solange die verlinkte Webseite existiert.

    Warum funktioniert mein QR-Code von einer anderen Webseite nicht mehr?

    Viele Generatoren erstellen standardmäßig dynamische QR-Codes. Diese enthalten einen Kurzlink zum Server des Anbieters, der jeden Scan an Ihre eigentliche Adresse weiterleitet. Endet die kostenlose Testphase oder das Abo, schaltet der Anbieter die Weiterleitung ab, und der gedruckte Code funktioniert nicht mehr. Codes von QRTurbo.app enthalten Ihren echten Inhalt und sind nie von uns abhängig.

    Ist QRTurbo.app wirklich kostenlos? Darf ich die Codes gewerblich nutzen?

    Ja. Es gibt keine Anmeldung, keine Testphase, kein Wasserzeichen und kein Scan-Limit. Sie dürfen die erstellten QR-Codes privat und gewerblich nutzen, etwa auf Visitenkarten, Speisekarten, Verpackungen und in der Werbung.

    Kann ich einen QR-Code nach dem Druck noch ändern?

    Nein. Ein statischer QR-Code lässt sich nicht bearbeiten, weil der Inhalt Teil des Musters ist. Wenn Sie das Ziel später ändern möchten, erstellen Sie den Code für eine Adresse, die Sie selbst verwalten, etwa eine Seite auf Ihrer eigenen Webseite, und ändern Sie stattdessen diese Seite.

    Wie groß sollte ich einen QR-Code drucken?

    Drucken Sie ihn mindestens 2 × 2 cm groß. Als Faustregel gilt: Der Code sollte mindestens ein Zehntel des Scanabstands messen. Ein Plakat, das aus 2 Metern Entfernung gescannt wird, braucht also einen Code von etwa 20 cm. Laden Sie für den Druck eine PDF- oder SVG-Datei herunter, die in jeder Größe scharf bleibt, und legen Sie die genaue Druckbreite fest. QRTurbo.app zeigt die Modulgröße an und warnt Sie, wenn der Code zu klein zum Scannen ist. Lassen Sie die Ruhezone um den Code frei.

    Warum lässt sich mein QR-Code nicht scannen?

    Die häufigsten Ursachen sind zu wenig Kontrast zwischen Code und Hintergrund, eine zu kleine Ruhezone, ein Logo, das zu viel vom Code verdeckt, oder zu viel Inhalt für die Druckgröße. QRTurbo.app prüft jeden Code mit einem integrierten Scanner auf Ihrem Gerät und schlägt Korrekturen vor. Testen Sie den Code vor dem Druck immer mit mehreren Handys.

    Sind meine Daten sicher? Können Sie mein WLAN-Passwort sehen?

    Ihre Daten bleiben auf Ihrem Gerät. Der QR-Code wird von Code erzeugt, der in Ihrem Browser läuft, und nichts, was Sie eingeben oder hochladen, wird an einen Server gesendet. Niemand kann also Ihr WLAN-Passwort oder Ihre Kontaktdaten sehen. Nach dem ersten Besuch funktioniert der Generator auch offline.

    Welches Dateiformat sollte ich verwenden?

    Verwenden Sie PNG für Bildschirme, Dokumente und die meisten Drucker. Verwenden Sie SVG für Websites und Designprogramme und PDF für Druckereien: Beides sind Vektordateien, die in jeder Größe scharf bleiben. EPS ist für ältere Grafik- und Schildersoftware gedacht. JPG und WebP sind kleine Bilddateien für Apps und Websites. Jedes Format ist kostenlos und behält Ihre Farben, Ihr Logo und Ihren Rahmen bei.
