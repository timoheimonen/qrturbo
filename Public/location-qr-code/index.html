    How location QR codes work

    An address creates a QR code with a Google Maps search link, which opens in a browser or map app on any phone. Coordinates create a geo link that opens directly in the phone’s default map app.

    Coordinates are the most precise choice for places without a street address, such as a cottage, a trailhead or the gate to an event area.

    Test the code on your own phone to check that it points to exactly the right place.

    Frequently asked questions

    Do QR codes made with QRTurbo.app expire?

    No. QRTurbo.app creates static QR codes: your link, text or contact details are encoded directly in the code. There is no server in between, so there is nothing that could expire or be switched off. A code keeps working as long as its content is valid, for example as long as the website it links to exists.

    Why did my QR code from another website stop working?

    Many generators create dynamic QR codes by default. They contain a short link to the provider’s server, which redirects each scan to your real address. When a free trial or subscription ends, the provider switches off the redirect and the printed code stops working. Codes from QRTurbo.app contain your real content and never depend on us.

    Is QRTurbo.app really free? Can I use the codes commercially?

    Yes. There is no sign-up, no trial, no watermark and no scan limit. You may use the QR codes you create for personal and commercial purposes, such as business cards, menus, packaging and advertising.

    Can I change a QR code after printing it?

    No. A static QR code cannot be edited, because the content is part of the pattern. If you expect to change the destination, create the code for an address you control, such as a page on your own website, and update that page instead.

    How large should I print a QR code?

    Print it at least 2 × 2 cm (0.8 × 0.8 in). As a rule of thumb, make the code at least one tenth of the scanning distance: a poster read from 2 metres away needs a code of about 20 cm. For print, download a PDF or SVG, which stay sharp at any size, and set the exact print width. QRTurbo.app shows the module size and warns you when the code is too small to scan. Keep the quiet zone around the code empty.

    Why won’t my QR code scan?

    The most common causes are low contrast between the code and its background, a quiet zone that is too small, a logo that covers too much of the code, or too much content for the printed size. QRTurbo.app checks every code with a built-in scanner on your device and suggests fixes. Always test the code with a few different phones before printing.

    Is my data safe? Can you see my WiFi password?

    Your data stays on your device. The QR code is generated by code running in your browser, and nothing you type or upload is sent to a server, so no one can see your WiFi password or contact details. After the first visit, the generator also works offline.

    Which file format should I use?

    Use PNG for screens, documents and most printers. Use SVG for websites and design tools, and PDF for print shops: both are vector files that stay sharp at any size. EPS is for older design and sign-making software. JPG and WebP are small image files for apps and websites. Every format is free and keeps your colors, logo and frame.
